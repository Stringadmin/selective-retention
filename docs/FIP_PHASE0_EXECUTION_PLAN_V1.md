## 1. 核心判断

F（0.4915）差于 E（0.4555）：FFN 特征隔离机制目前在 Phase 0 上是负收益。
三份诊断（G/H/I）共同结论：
1. FFN-only 隔离边界太窄，非 FFN 参数是主要覆写路径（G 证明冻结非 FFN 遗忘降 38.8% 但可塑性崩）；
2. 全局单一 quantile/scale 不足（H 的 q/scale 响应非单调）；
3. 全局 sticky 掩码保护了错误的行（I 负结果）。

因此 Phase 0 冲刺分四步：**先归因 → 再设计 v1 → 达标后 5 种子 → Phase 1（条件）**。
